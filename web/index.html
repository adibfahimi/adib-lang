A tiny language.
Written from scratch in Rust.

Adib Lang is a JavaScript-flavored interpreter with variables, closures, recursion, arrays, and a hand-written lexer and parser. Edit the program, press Run, and watch the real Rust interpreter execute it.

Hand-written pipeline

          

            Lexer, recursive-descent parser, AST, and tree-walking interpreter —
            no parser generators, no interpreter crates.
          

        


        

          02
          
Real language semantics

          

            Lexical scoping, first-class functions, closures, recursion,
            short-circuit logic, and runtime errors with source positions.
          

        


        

          03
          
One Rust core

          

            The same interpreter powers the CLI and this page. The browser build
            is compiled to WebAssembly with wasm-bindgen.
          

        


        

          04
          
Tested in CI

          

            Unit and end-to-end tests cover the lexer, parser, interpreter, and
            every example program. Formatting and clippy are enforced.
